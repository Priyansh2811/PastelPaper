# Project Workflow & Folder Structure

This document explains how the PastelPaper project is organized and how
data flows from upload to export.


## Folder Structure

```
PastelPaper/
├── index.html                # Vite entry HTML; mounts #root
├── vite.config.js            # Vite + React + Tailwind plugin config
├── eslint.config.js          # ESLint rules
├── package.json              # Scripts and dependencies
├── public/                   # Static assets served as-is (filter thumbnails, logos, icons)
│   ├── retro.png, sunny.png, bw.png, ...   # filter preview thumbnails
│   └── logo.png, icon.png, color-wheel.png
├── dist/                     # Production build output (generated by `npm run build`)
└── src/
    ├── main.jsx              # React entry; renders <App /> into #root
    ├── App.jsx               # Root component — orchestrates Sidebar, PreviewCard, and ActionBar
    ├── App.css / index.css   # Global styles + filter/text utility classes (the CSS "engine")
    ├── assets/               # Bundled assets imported by code
    ├── store/
    │   └── useStore.js       # Zustand store managing all global state
    └── components/
        ├── Sidebar.jsx       # Left control panel (tabs, design, text, filters, effects, stickers)
        ├── PreviewCard.jsx   # Live card preview canvas
        ├── ActionBar.jsx     # Bottom action buttons (upload, adjust, reset, export)
        ├── presets.js        # Shared data: TEMPLATES (dimensions) and LIGHT_LEAKS gradients
        ├── cropModal.jsx     # Crop dialog (aspect ratios, zoom) → returns cropped image + aspect
        ├── filter.jsx        # Filter picker; toggles filter classes on <html>
        ├── bgcolor.jsx       # Background color picker (toggles color classes on <html>)
        ├── bold.jsx          # Text style toggles (bold/italic/underline/strike)
        ├── fontstyle.jsx     # Font-family dropdown
        ├── templates.jsx     # Template/format selector (Classic, Square, Story, Polaroid)
        ├── effects.jsx       # Sliders for grain, vignette, light leaks, date stamp
        ├── stickers.jsx      # Emoji/text palette and per-sticker controls
        ├── stickerLayer.jsx  # Renders stickers on the card; drag/scale/rotate via pointer events
        ├── exportbar.jsx     # Format toggle (PNG/JPG) + download/copy/share buttons
        └── link.jsx          # Social links (GitHub / X)
```

## Architecture Overview

The app is a **single-page React app with centralized state via Zustand**. `App.jsx` is the
orchestrator: it delegates UI rendering to `<Sidebar />`, `<PreviewCard />`, and `<ActionBar />`.

There are two complementary styling mechanisms:

1. **React state** — for structural/data-driven values: the image, crop aspect
   ratio, template, effects intensities, stickers, frame type, etc. These drive
   inline styles and conditional classes on the card.
2. **Global CSS classes on `<html>`** — filters, background color, and text
   styles are applied by toggling classes on `document.documentElement`. The
   matching rules live in `index.css` / `App.css`. Components like `filter.jsx`,
   `bgcolor.jsx`, and `bold.jsx` add/remove these classes directly.

## Data Flow

```
Upload ──> rawImage (original, kept for re-cropping)
              │
              ▼
        CropModal ──onApply(url, aspect)──> image + imageAspect
              │
              ▼
   ┌──────────────────────────────────────────────┐
   │              Card Preview (PreviewCard.jsx)   │
   │  template dims (presets.js)                   │
   │  + frame (default / custom / pattern)         │
   │  + photo box sized to imageAspect             │
   │  + CSS filter classes on <html>               │
   │  + effects (grain / vignette / light leak)    │
   │  + StickerLayer (stickers & text)             │
   └──────────────────────────────────────────────┘
              │
              ▼
   ExportBar ──> html-to-image (toPng / toJpeg) ──> download / copy / share
```

### Step by step

1. **Upload** — the user selects a file. The original is stored as `rawImage`
   so it can be re-cropped later.
2. **Crop** — `CropModal` opens with `rawImage`. The user picks an aspect ratio
   (1:1 / 3:4 / 4:3 / Original) and zoom. On apply, it draws the selected region
   to a canvas and returns a PNG data URL **plus the crop's aspect ratio**.
   `App.jsx` stores these as `image` and `imageAspect`.
3. **Frame & layout** — the photo box uses `imageAspect` (standard layout) so the
   cropped image is shown at its true ratio rather than forced into a square.
   `photoLayout === 'full'` instead fills the whole card. A custom frame can be
   used as a background or overlay.
4. **Template** — `presets.js` `TEMPLATES` defines the capture-box width/height
   for Classic / Square / Story / Polaroid. This is the source of truth for both
   the preview and the exported size.
5. **Filters & color** — `filter.jsx` / `bgcolor.jsx` toggle classes on `<html>`;
   the CSS rules transform the photo and background.
6. **Effects** — `effects.jsx` sliders feed `grain`, `vignette`, and
   `lightLeak` state, rendered as overlay layers on the card.
7. **Stickers & text** — `stickers.jsx` adds layers to the `stickers` array;
   `stickerLayer.jsx` renders them and handles move/scale/rotate via pointer
   events. Coordinates are in px relative to the card top-left (the card is not
   CSS-scaled, so 1px pointer move = 1px position change).
8. **Export** — `exportbar.jsx` triggers `html-to-image` (`toPng`/`toJpeg`) on
   the card ref. During capture, sticker selection chrome is hidden
   (`interactive = false`) so the output is clean. The result is downloaded,
   copied to the clipboard, or shared via the Web Share API where available.

## State Ownership (Zustand Store)

All major editor state lives in `src/store/useStore.js`, including (non-exhaustive):

| State | Purpose |
|-------|---------|
| `image` / `rawImage` | Cropped photo / original upload |
| `imageAspect` | Aspect ratio of the cropped photo (sizes the photo box) |
| `imageFit` | `cover` or `contain` |
| `cropOpen` | Whether the crop modal is shown |
| `frameType` / `customFrame` / `patternIndex` / `frameMode` | Default vs custom vs pattern frame and how it's drawn |
| `photoLayout` | `standard` (aspect box) vs `full` (fills card) |
| `template` | Selected layout from `TEMPLATES` |
| `filter` | Active filter name |
| `grain` / `vignette` / `lightLeak` / `dateStamp` | Film effects |
| `stickers` / selected sticker id | Sticker & text layers |
| `title` / `date` / `font` / `color` / `textColor` | Text content and styling |

Child components consume this state directly via `useStore()`, 
keeping the card preview the single rendered source of truth without extensive prop drilling.

## Conventions

- **Styling**: Tailwind utility classes inline; global filter/text/color rules
  in `index.css` / `App.css` toggled via classes on `<html>`.
- **Presets as source of truth**: template dimensions and light-leak gradients
  live in `presets.js` and are shared by previews and export.
- **No backend**: everything (crop, filters, export) runs in the browser.

## Common Tasks

- **Add a filter**: add an option in `filter.jsx`, a thumbnail in `public/`, and
  the matching CSS rule(s) in `index.css` / `App.css`.
- **Add a template**: add an entry to `TEMPLATES` in `presets.js`.
- **Add a light leak**: add an entry to `LIGHT_LEAKS` in `presets.js`.
- **Add a sticker**: add an emoji to the `EMOJIS` list in `stickers.jsx`.
